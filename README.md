# Design Patterns in C# 

A collection of Gang of Four design pattern examples implemented with modern C# and .NET. 
Each design pattern is implemented as an independent executable project so that every example can be explored and run separately. 

## Categories 

### Creational 
- Factory Method 
- Abstract Factory 
- Builder 
- Prototype 
- Singleton 

### Structural 
- Adapter 
- Bridge 
- Composite 
- Decorator 
- Facade 
- Flyweight 
- Proxy 

### Behavioral 
- Chain of Responsibility 
- Command 
- Interpreter 
- Iterator 
- Mediator 
- Memento 
- Observer 
- State 
- Strategy 
- Template Method 
- Visitor 

## Development Environment 
- .NET 10 - C# 
- Visual Studio Code 
- Git
